# About DARA-GPT

DARA-GPT is an AI-focused mobile workspace designed to feel less like a generic chatbot and more like a reflective operating layer for thought, planning, and personal context.

This project is a custom Expo + React Native application built around a calm, dark, futuristic interface. The product concept blends conversational AI, memory, planning, and personal insight tools into a single app experience.

## Project vision

The core idea behind DARA-GPT is to create an assistant that feels like a "thinking companion" rather than just a prompt box. The app is organized around the idea that users should be able to:

- have focused conversations with an AI
- work through ideas in different response modes
- keep context and memory active across sessions
- organize tasks and planning around life rhythms
- map personal patterns and growth areas
- move between deep reflection and practical execution

## What the app includes

### 1. AI chat experience
The app includes a conversational interface with layered reasoning and multiple modes:

- Insight
- Technical
- Narrative

Users can adjust the active reasoning layer from 1 to 6, giving the experience a strong "depth control" feel. This is reflected in the UI language such as “L5 · INSIGHT STREAM” and the live thinking pulse.

### 2. Memory and context
The project includes a memory-oriented design where the assistant can keep track of project context and loaded memory nodes. This suggests an architecture where the app can support persistent context instead of treating every prompt as isolated.

### 3. Planning and progression
The app includes a Plans screen and a plan system built with Redux. This allows tiers and unlock states such as:

- free
- personal
- team
- business

Features like calendar access, personality insight, advanced layers, and memory depth are gated behind plan progression, which gives the app a productized SaaS feel.

### 4. Calendar and task flow
The project includes a calendar-focused experience for thought reminders and scheduling. This implies the product is designed not only for conversation, but also for grounding AI support in real-world routines and planning cadence.

### 5. Personality and self-mapping
The Personality screen and Redux state suggest the app is intended to evolve beyond simple productivity. It adds a reflective dimension where the user’s patterns, tendencies, and growth vectors can be visualized and explored.

## Product style and design language

The design language is intentionally distinctive:

- dark-first UI
- cool blue / purple / cyan accents
- atmospheric gradients
- soft glassmorphism panels
- calm, minimal interface language

This visual treatment reinforces the product’s identity as a meditative AI interface rather than a standard business dashboard.

## Tech stack

This codebase is built with:

- Expo / React Native
- Expo Router
- Redux Toolkit
- TypeScript
- NativeWind / Tailwind styling
- React Navigation

The app structure is organized into feature-oriented sections, including:

- app/ for screen routes and layout
- screens/ for page-level UI
- redux/ for state management
- components/ for shared UI
- constants/ for theme definitions

## Current status

This repository is an early-stage product prototype and UI concept for DARA-GPT. The code demonstrates the app’s direction and interaction model rather than a complete production backend or fully integrated AI service.

At present, the app is structured as a front-end foundation for a personal AI system with:

- conversational AI interactions
- layered reasoning modes
- memory-aware UI patterns
- productivity and planning flows
- reflective self-guidance features

## Summary

DARA-GPT is best understood as a concept app for an AI-powered personal operating system: a space for conversation, memory, planning, and self-awareness. It is intentionally designed to feel immersive, intelligent, and calm, positioning the assistant as a digital companion for daily thinking and decision-making.
